# Orchard Valley Resort

Official website for Orchard Valley Resort — a mountain and orchard-themed cottage resort near Chail, Himachal Pradesh. Built with Next.js, TypeScript, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Configuration

Resort details (WhatsApp number, address, contact info, social links) are centralized in `lib/config.ts`. Room data lives in `lib/rooms.ts`.

## Deploy

Deployed on [Vercel](https://vercel.com).
